# LectureAI - Intelligent Lecture Analysis Platform

An AI-powered platform that captures and analyzes lectures in real-time, providing automatic summaries, interactive chat assistance, and organized slide reviews for enhanced learning experiences.

## 🚀 Features

### 📹 **Live Lecture Capture**
- **Screen Capture**: Real-time analysis of visual content from presentations and slides
- **Audio Recording**: High-quality audio capture with live transcription
- **Smart Detection**: Automatic identification of slides, diagrams, and key visual elements

### 🤖 **AI-Powered Analysis**
- **Real-time Summaries**: Automatic generation of key points every minute
- **Content Understanding**: Deep analysis of both visual and audio content
- **Smart Annotations**: AI-generated insights and explanations

### 💬 **Interactive AI Chat**
- **Contextual Assistance**: Ask questions about current lecture content
- **Intelligent Responses**: AI provides explanations based on captured material
- **Quick Actions**: Pre-built prompts for common queries

### 📚 **Slide Review System**
- **Organized Library**: All captured slides with timestamps and metadata
- **Search & Filter**: Find specific content quickly
- **Annotation System**: Add personal notes and highlights
- **Export Options**: Download slides and notes for offline review

## 🎨 Design Features

- **Modern Dark Theme**: Professional interface optimized for extended use
- **Responsive Layout**: Works seamlessly on desktop and tablet devices
- **Beautiful Animations**: Smooth transitions and engaging micro-interactions

## 🎯 Usage

### Starting a Lecture Session
1. Click the **"Start Recording"** button in the top-right corner
2. Grant necessary permissions for screen capture and audio recording
3. The platform will begin analyzing content in real-time

### Using AI Chat
1. Switch to the **"AI Chat"** tab
2. Ask questions about the current lecture content
3. Use quick action buttons for common queries

### Reviewing Slides
1. Navigate to the **"Review Slides"** tab
2. Browse captured slides with timestamps
3. Search by keywords or filter by date
4. Click on slides to view annotations and AI analysis
